# FieldFlow

Интерфейс интеллектуального планирования выездных работ для кейса «Билайн Бизнес» на хакатоне «Лидеры цифровой трансформации».

## Что реализовано

- диспетчерский экран с картой маршрутов и очередью заявок;
- показатели назначений, пробега, SLA и загрузки инженеров;
- эвристическая VRPTW-оптимизация с лексикографической целью: сначала число активных инженеров, затем пробег;
- first-fit baseline по ТЗ: заявки идут в исходном порядке к первому совместимому свободному инженеру без глобальной перестановки;
- фильтрация по территориям: Восток, Юго-восток и Югоцентр;
- сценарий добавления срочной заявки и наглядное отображение влияния на план;
- объяснение причин назначения заявки конкретному инженеру;
- адаптивная компоновка для ноутбука, планшета и телефона;
- сравнение baseline/VRPTW только после полного геокодирования адресов;
- кэш геокодирования с явными уровнями качества `precise`, `approximate` и `not_found`.

Интеграционные точки подготовлены для будущего подключения FastAPI, OR-Tools, PostgreSQL, OSRM и Яндекс API. Текущая браузерная эвристика остаётся воспроизводимым baseline решения и не заявляет математически доказанную оптимальность.

## Данные

Исходные CSV используют кодировку Windows-1251 и разделитель `;`. В трёх синтетических наборах 205 заявок: Восток — 66, Юго-восток — 83, Югоцентр — 56. После двух пустых строк в каждом файле находится адрес офиса; импортёр должен обрабатывать его как стартовую точку, а не как заявку.

Контрольные распределения используются для построения пула из 35 инженеров, но не используются как baseline. Адреса геокодируются бесплатными OSM-сервисами Photon и Nominatim командой `node scripts/geocode-addresses.mjs`; результат инкрементально хранится в `data/geocoding-cache.json`. Импорт запускается командой `node scripts/import-csv.mjs`.

В исходных CSV нет нормативов длительности, транспорта и отдельных матриц навыков/оборудования. До появления справочников приняты и явно записаны в метаданных допущения: 45 минут на работу, автомобиль, смена 08:00–22:00, расчётная скорость 32 км/ч. Исходные типы работ сведены в три категории навыков: подключение, телевидение, диагностика и ремонт.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Production-сборка:

```bash
npm run build
npm run start
```
