# Генератор заявок и инженеров

Отдельный пакет: карта и UI диспетчера в корне репозитория не затрагиваются.

Адреса — реальные здания OSM (улица и номер дома), не вестибюли метро. Заявки ставятся в рабочие здания, стартовые точки инженеров — в жилые дома, точки разносятся по районам.

## Запуск

```bash
cd generator
npm install
npm run generate
npm run dev
```

Без флагов CLI спросит параметры. С флагами сразу пишет файлы:

```bash
npm run generate -- --engineers 12 --jobs 40 --seed 42 --out datasets/sample
```

- `npm run generate` — JSON/CSV набор
- `npm run generate -- --catalog-only` — справочник задач и навыков
- `npm run dev` — экран параметров и скачивание файлов
- `npm run fetch-buildings` — обновить каталог домов OSM (нужна сеть)

Выход: `datasets/sample` (демо) или `datasets/latest` (последний прогон, в git не попадает).

У заявки один навык из трёх: «Локальные работы», «Работы на подключение и дозаказы», «Аварийные работы». У инженера от одного до трёх этих навыков и один транспорт. Требуемый транспорт заявки пуст, если ограничения нет. В набор входят события перепланирования. FieldFlow читает `dataset.json` и CSV на вкладке «Заявки».
